Bing Beats · Apr 2026

An app for discovering music by place and time. Pick a country on a Mapbox globe and a year on a slider, and it lists the tracks that defined that place and moment, with 30-second previews and links to the full songs on Spotify. A Gemini-powered music guide chats about the local scene and can suggest playlists. The Node.js back end searches Spotify by year and market, caches access tokens, fills in missing previews through iTunes, and keeps API keys off the client. Runs on iOS, Android, and the web.

Built with: TypeScript, React Native, Expo, Node.js, Express

MegaGem Live · Feb – Jul 2026

A digital version of Jane Street's hidden-information auction game MegaGem, where you play against two AI bidders. At the start of each round, half the gems are secretly dealt out as private information, and winning an auction forces you to reveal one of them, so every bid is a trade between value and information.

The Flask-SocketIO auction engine handles bidding, private gem reveals, tie-breaks, and settlement; spectators only ever receive a redacted game state, so private gems never leak. The two AI bidders call the Gemini API and return validated, legal bids, with a rule-based fallback if the API call or parsing fails. The game is rendered as a first-person 3D auction room in Three.js, with the live HTML interface embedded through CSS3DRenderer, and includes an AI coach and a tutorial for new players.

Built with: Python, Flask-SocketIO, JavaScript, Three.js, Gemini API
